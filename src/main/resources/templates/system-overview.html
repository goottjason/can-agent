시스템 소개

CANSLIM + 컵앤핸들 자동매매 시스템 전체 구조

목차

  • 전체 개요 - 시스템 아키텍처와 핵심 흐름
  • 모니터링 방식 - 자동 스캔 → 매수/매도 흐름
  • CANSLIM 점수 체계 - 6개 요소별 점수 기준
  • 컵앤핸들 알고리즘 - 패턴 탐지 및 점수 산출
  • 매매 전략 - 매수/매도 조건, 포지션 사이징

시스템 아키텍처

기술 스택

구분기술
백엔드Spring Boot 3.3, Java 17, Spring Data JPA
데이터베이스PostgreSQL 16 (Docker)
증권사 API한국투자증권 Open API (실전 계좌)
배포Docker Compose, Nginx 리버스 프록시
알림Telegram Bot
프론트엔드Thymeleaf (서버 사이드 렌더링)

핵심 흐름

1단계: 데이터 수집
매일 04:00 ET SEC 나이틀리 배치 이후 가격·재무 데이터 동기화
분기별 DART 재무제표 수집 → 금융지표 계산

▼

2단계: 점수 산출
매일 07:00 ET 전체 활성 종목 CANSLIM + 컵앤핸들 분석
→ analysis_scores 테이블에 종목별 일일 점수 저장 (UPSERT)

▼

3단계: 장중 모니터링
09:30~16:00 ET 5분마다 순환
  ① 보유 종목 매도 체크 (손절·익절·점수하락)
  ② ~400종목 스캔 → 매수 신호 탐지
  ③ 매수 주문 실행 (최대 3회 재시도)
  ④ Telegram 알림 발송

▼

4단계: 리스크 관리
손절: -7% | 익절: +20% | 최대 보유: 10종목 | 종목당 한도: 10%

데이터베이스 구조

테이블설명주요 컬럼
stocks상장종목 마스터code, name, market, sector, active
stock_prices일별 가격/거래량open, high, low, close, volume, change_rate
financial_statements분기별 재무제표revenue, operating_profit, net_income, eps, roe
analysis_scores종목별 일일 분석 점수can_slim_score, cup_score, total_score (UPSERT)
portfolios보유 종목 현황quantity, avg_buy_price, current_price, profit_rate
trades매매 기록trade_type (BUY/SELL), price, quantity, reason

환경 설정
