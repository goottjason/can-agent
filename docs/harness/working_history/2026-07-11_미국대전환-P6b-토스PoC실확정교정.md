## 왜 했나 — PoC가 잡은 실제 어긋남
설계 스펙 기반 추정 상수가 실제와 다른 부분을 라이브로 확정:
- **전 응답 `result` 래핑** (우리는 루트 파싱) — 특히 캔들이 `result.candles`라 **시세 0건 조용한 버그**였음.
- 잔고 `/api/v1/assets`는 **404**(경로 없음), 현금 필드 `availableCash`도 틀림.
- 환율 필수 파라미터 누락, 소수매도 규칙 상이, OrderStatus `CLOSED` 부재.

## 무엇을 고쳤나

### 1. 응답 `result` 언랩 (🔴 캔들 버그 포함)
- `TossCandleClient.parse()`: `result.candles`/`result.nextBefore` 언랩 추가. 루트 파싱이면 0건이던 회귀를 result-래핑 픽스처 테스트로 고정.
- `TossBrokerAdapter`: `unwrap()` 헬퍼로 buying-power·holdings·주문POST·주문상세·환율 전 호출에 적용.

### 2. 잔고 재배선
- `/api/v1/assets`(404) 제거 → **`GET /api/v1/buying-power?currency=USD`**(→`result.cashBuyingPower`=USD 예수금) + **`GET /api/v1/holdings`**(→`result.items[]`, 금액 `{krw,usd}` 중첩 — 총평가=`marketValue.amount.usd`) 2콜 합성.
- `BrokerBalance` record shape **불변**(대시보드 무영향).

### 3. 계좌 헤더
- 계좌콜(buying-power/holdings/orders)에 **`X-Tossinvest-Account: <accountSeq>`**. accountSeq = `GET /api/v1/accounts` `result[0].accountSeq` 조회·캐시, `TOSS_ACCOUNT` env override 우선.

### 4. 현재가 구현
- `getCurrentPrice` 0 스텁 제거 → **`GET /api/v1/prices?symbols=<sym>`** → `result[0].lastPrice`.

### 5. 환율
- **`?baseCurrency=USD&quoteCurrency=KRW`** 파라미터 추가, `result.rate` 언랩.

### 6. 주문 매핑 교정
- 소수매수 = `orderAmount`+`MARKET`(price 금지), 정수지정가 = `quantity`+`LIMIT`+`price`(US 정밀 <$1 4자리/≥$1 2자리 반올림).
- **소수매도 교정**: 실 API 규칙(소수매도=`quantity`(소수)+`MARKET`+`SELL`, price 금지)을 **어댑터 경계 안**에서 적용 — 포트 `OrderSpec`(Notional/Limit sealed)·전략 로직 무변경(SELL+Limit+소수수량 → MARKET+quantity, 정수 → LIMIT). KIS가 Limit를 정수호가로 변환하는 것과 대칭.
- **`clientOrderId`(UUID) 멱등성 키**(10분) 추가 — 중복주문 방지. 응답 `result.orderId`.

### 7. 주문상태/체결
- `GET /api/v1/orders/{orderId}` → 체결 **`execution.{filledQuantity,averageFilledPrice,commission,tax,filledAt,settlementDate}`** 중첩 매핑. `averageFilledPrice` 오타 교정.
- **OrderStatus enum**: `CLOSED` 삭제→`FILLED`, 실제 값집합(`PENDING,PENDING_CANCEL,PENDING_REPLACE,PARTIAL_FILLED,FILLED,CANCELED,REJECTED,CANCEL_REJECTED,REPLACE_REJECTED,REPLACED`).

### 8. 기타
- `TossTokenProvider` DEFAULT_EXPIRES_IN 3600→86399(24h), 확정 주석. 상수 주석 `=== PoC 확정(2026-07-11) ===`.
