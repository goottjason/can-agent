## 실행 중 발견·수정한 버그 2건 (`scripts/toss-poc-order.sh`)
이 PoC는 체크리스트상 여태 **실제 실행된 적이 없어**(장중+승인 게이트) 미검증 상태였고, 실행하자 2개 버그가 드러남:

1. **`jget` JSON 파서 완전 고장** — 경로(`$1`)를 파이썬 코드 문자열에 직접 삽입(`eval('d'+'$1')`)해, 경로에 든 작은따옴표가 파이썬 리터럴을 깨뜨림 → 모든 파싱이 빈 값 반환 → "토큰 실패"로 오인. 정적 JSON 격리 테스트로 확정.
   - 수정: 경로를 코드가 아닌 **`sys.argv`로 전달** — `python3 -c "...eval('d'+sys.argv[1])..." "$1"`.
2. **Phase1 주문취소 Content-Type 누락** — 취소 POST에 `application/json` 헤더(`${JSON[@]}`) 미포함 → `unsupported-content-type` 에러로 취소 실패, 실계좌에 미체결 주문이 열린 채 남음.
   - 수정: 취소 curl에 `${JSON[@]}` 추가. 열려 있던 주문은 올바른 헤더로 즉시 취소(CANCELED 확인).

수정은 **로컬 repo + 서버 사본** 모두 반영. **origin 미푸시(커밋 대기)**.
