# 미국 대전환 P5 — 토스 캔들 어댑터(MarketDataPort) + fetch 루프 역전

날짜: 2026-07-09 · 브랜치: us-pivot · 리스크: 표준(외부연동 신규, 매매로직 불변) · 판정: QA PASS

## 배경
P4(EDGAR 재무)에 이은 시세측 연동. 토스 캔들로 StockPrice를 채워 컵앤핸들·이동평균(50/200MA) 입력을 확보. 첫 토스 연동이라 OAuth 공용 인프라(TossTokenProvider)도 함께 세움.

## 변경 요약
**신규**
- `config/TossProperties` — `toss.app-key/app-secret/base-url/token-url`.
- `config/TossTokenProvider` — OAuth2 client_credentials 토큰 캐시(만료 전 갱신·synchronized·invalidate), KoreaInvestmentTokenProvider 패턴 이식. 캔들·주문 공용(P6 재사용).
- `service/toss/TossCandleClient` + `TossCandle`/`TossCandlePage` — `GET /api/v1/candles` interval=1d, count≤200, before/nextBefore 페이지네이션, 토큰 헤더, 오류 견고.
- `service/toss/TossMarketDataAdapter implements MarketDataPort` — 유일 포트 빈. active 종목(ticker 있는) 각각 캔들 백필→StockPrice upsert. 루프 "날짜별 전종목"→"종목별 캔들" 역전(40페이지 상한).
- `service/StockPriceUpserter` — StockPrice 생성·중복체크·저장 공유 헬퍼(토스가 사용, Krx는 인라인 유지).

**수정**
- `KrxDataSyncService`: `implements MarketDataPort` 제거(클래스·메서드 불변, P9 삭제 예정).
- `DataSyncScheduler`: price 동기화 의존 구체 KrxDataSyncService→MarketDataPort(P1 잔여 디커플 완성). syncDailyData·runBulkPriceSync 둘 다 포트 경유.
- `application.yml`: toss 설정.
