# 미국 대전환 P1 — 포트 인터페이스 seam 추출 + 호출부 디커플

날짜: 2026-07-09 · 브랜치: us-pivot · 리스크: 표준(순수 리팩터링, 동작 불변) · 판정: QA PASS

## 배경
CAN-Agent를 국내(KIS)→미국(토스 Open API + SEC EDGAR)으로 대전환하는 트랙의 첫 코드 단계. 사전조사 4종(`_workspace/B~E`)에서 "CANSLIM 엔진은 그대로, 브로커·데이터·시간 껍데기만 교체" + "현재 어댑터 이음새 0개(구체클래스 직접주입)"가 확인됨. P1은 그 이음새(포트 인터페이스)를 만드는 안전 리팩터링.

## 변경 요약 (동작 100% 불변)
- **신규 포트 3개** (`com.canagent.port`):
  - `BrokerPort` ← KoreaInvestmentApiClient (buy/sell/getBalance/getCurrentPrice, 기존 int·KIS DTO 시그니처 그대로)
  - `MarketDataPort` ← KrxDataSyncService (syncAllActiveStocks(LocalDate,LocalDate))
  - `FinancialsPort` ← DartDataSyncService (syncAllActiveStocks(String,String), importFromJsonFile(String))
- **구현체 3개**: 기존 KIS/KRX/DART 클래스가 각 포트를 `implements`(@Override만 추가, @Service 유지).
- **호출부 4곳 디커플**: TradingStrategyService·IntradayMonitorWorker·PortfolioScheduler·DashboardController의 주입 타입을 구체클래스→포트 인터페이스로. 호출 로직 무변경.
- **MarketCalendarPort는 P7로 이월**(거래시간 판정이 워커 내부라 P1에서 억지 추출 위험).
