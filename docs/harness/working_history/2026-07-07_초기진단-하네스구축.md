## 핵심 발견 (정적 진단)

1. **min-score=120은 구조적으로 과도**: CANSLIM 만점이 100이라 컵앤핸들 패턴(30~70점) 없이는 어떤 종목도 매수 불가. 컵 패턴은 65주 이력+엄격 기준이라 희소. 유력한 1차 원인.
2. **데이터 결핍 → 0점 연쇄**: 재무제표(DART) 없으면 C+A=0(최대 -40), 주가 이력 <200일이면 M 부분/0, 업종 없으면 L=0. 분석기들은 데이터 부족 시 조용히 0점 반환하며 사유가 DB에 저장되지 않음.
3. **silent return 7곳**: IntradayMonitorWorker의 탈락 지점 대부분이 무로그 — "왜 안 잡혔는지"를 알 수 없는 구조적 원인.
4. **설정 불일치**: min-score 기본값이 워커(120) vs TradingStrategyService(60)로 이중 정의.
5. **후보 선정이 어제 데이터 의존**: KRX 동기화 실패 시 후보 0 → 검사 자체가 공회전.
6. 대시보드는 SSR 전용·Top-N 리더보드 없음·`/api/monitor/status` 미사용 — 요구사항은 `dashboard-requirements.md` R1~R5로 명세화 완료.
