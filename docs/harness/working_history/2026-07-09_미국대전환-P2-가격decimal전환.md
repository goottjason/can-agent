# 미국 대전환 P2 — int→BigDecimal 가격 전환

날짜: 2026-07-09 · 브랜치: us-pivot · 리스크: 표준(타입 확장, KRW 동작 불변) · 판정: QA PASS

## 배경
P1(포트 추출)에 이은 대전환 두 번째 코드 단계. 최우선 correctness 단계 — 기존 코드가 가격을 `int`로 받고 `price.intValue()`로 절삭해 원화는 무손실이나 **미국 USD 센트가 붕괴**하는 지점을 전면 제거. 현재는 KIS(원화 정수)만 흐르므로 동작은 100% 불변.

## 변경 요약 (KRW 바이트 동일, USD 무손실)
- **BrokerPort.buy/sell** `int price`→`BigDecimal price`, **getCurrentPrice**·`KoreaInvestmentPriceResponse.getCurrentPrice()` int→BigDecimal(파서 parseInt→new BigDecimal).
- **TradingStrategyService** 주문 호출부의 `price.intValue()` 절삭 제거 → BigDecimal 무손실 전달.
- **KIS 절삭 격리**: `KoreaInvestmentApiClient.executeOrder` 내부에서만 `price.setScale(0,HALF_UP)`로 KRW 정수호가(ORD_UNPR) 변환(주석 명시). 시장가 판정 `price==0`→`price.signum()==0`. 포트 계약은 무손실.
- **IntradayMonitorWorker** 현재가 소비 2곳 `new BigDecimal(int)` 래핑 제거 + `compareTo(ZERO)` 가드. **PortfolioScheduler** BigDecimal 직접 소비.
- **NotificationEvent.formatPrice** `%,d`(longValue) 절삭 제거 → `DecimalFormat("#,##0")`+`maxFractionDigits=scale`(KRW "70,000" 동일, USD 센트 보존). 통화기호·로케일은 P8 소관이라 무변경.
