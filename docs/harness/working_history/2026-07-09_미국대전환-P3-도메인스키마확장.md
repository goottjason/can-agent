# 미국 대전환 P3 — 도메인 스키마 확장 (additive)

날짜: 2026-07-09 · 브랜치: us-pivot · 리스크: 표준(additive 스키마, 동작 불변) · 판정: QA PASS

## 배경
P1(포트)·P2(가격 decimal)에 이은 세 번째 코드 단계. 미국 식별(ticker/cik/exchange)과 SEC 재무(periodType 등) 필드를 도메인에 심는다. **순수 additive** — 새 필드는 nullable, 기존 생성자·시그니처 유지로 KR 동작 100% 불변.

## 재스코프 (P4 이관)
설계 §2.2의 "AnnualEarningsAnalyzer Q4→periodType 1줄 수정"은 **P4로 이관**. KR 데이터에 periodType 미충전 상태에서 지금 바꾸면 A-스코어 붕괴 → EDGAR가 periodType을 채우는 P4에서 분석기 lookup 전환. P3는 필드만 심음(채워지지 않아도 무해).

## 변경 요약 (전부 additive)
- **신규** `domain/stock/FiscalPeriodType.java` enum { QUARTER, ANNUAL }.
- **Stock**: nullable US 식별필드 5개(`ticker`/`cik`/`exchange`/`currency`/`sicCode`) + getter/setter + 편의 `applyUsIdentifiers(...)`. 4인자 생성자·기존 필드 무변경.
- **FinancialStatement**: `periodType`(@Enumerated STRING, nullable)·`currency`(nullable) 추가, `fiscalQuarter` nullable 완화(연간행 수용), `eps` scale 2→4, `debtRatio` precision 5→12. 4인자 생성자·`updateFinancials` 6인자 시그니처 무변경, 새 필드 setter로만.
