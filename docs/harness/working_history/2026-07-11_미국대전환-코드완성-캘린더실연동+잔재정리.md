## #5 — TossMarketCalendarAdapter: 정적 휴일폴백 → 토스 US 캘린더 실연동
PoC로 확정한 `GET /api/v1/market-calendar/US?from=d&to=d` 실연동(P7의 정적 NYSE 휴일폴백 대체).
- `result` 언랩 + Bearer + `X-Tossinvest-Account: accountSeq`(TossBrokerAdapter와 동일 조회·캐시).
- `isTradingDay(d)` = `result.today.regularMarket != null`. `isMarketOpen(now)` = `today.regularMarket [startTime,endTime]`(KST+09:00 → Instant, =ET 09:30~16:00) 경계 포함.
- **폴백 보존**: 토큰없음·API예외·4xx(401→invalidateToken)·result/today 부재 시 기존 정적 NYSE 휴일 폴백으로 안전 전환(무로그 return 없음, 로직 원형 보존).
- `MarketCalendarPort` 시그니처(isTradingDay/isMarketOpen) 불변 → MarketHours(P7) 소비 무영향.
- 픽스처 `market-calendar-{trading,holiday}.json`, 어댑터 테스트 10(경계·휴장·폴백·401·미국휴일 6종).
