# 미국 대전환 P4 — EDGAR 재무 어댑터 + 유니버스 로더 + 분석기 하위호환

날짜: 2026-07-09 · 브랜치: us-pivot · 리스크: 표준+(첫 실외부연동 + 분석기 하위호환) · 판정: QA PASS

## 배경
P1~P3(포트·가격·스키마 안전단계)에 이은 첫 실외부연동. SEC EDGAR(완전무료·상업OK)로 CANSLIM C·A 재무입력을 조달. 토스 못 주는 재무 공백을 $0로 메우는 하이브리드의 데이터측 뼈대.

## 변경 요약
**신규 (com.canagent.service.edgar)**
- `EdgarClient` — companyfacts REST(CIK별), User-Agent 헤더 필수, 125ms rate-limit(10 req/s 준수), 4xx/5xx 견고.
- `EdgarCompanyFactsParser` — 순수 파서(Spring 무의존). XBRL→FinancialStatement. **기간을 fy/fp 아닌 start/end 지속기간으로 분류**(~1년→ANNUAL/quarter=null, ~1분기→QUARTER), YTD 반기·9개월 제외로 standalone 분기 적재. roe=순이익/자본×100·debtRatio=부채/자본×100(연간행만, 0/누락 방어).
- `EdgarFinancialsAdapter implements FinancialsPort` — 유일 포트 빈. 기존 영속화/updateFinancials/중복체크 재사용.
- `SecTickerUniverseLoader` — company_tickers.json→Stock(ticker/cik/exchange) upsert. 국내보통주 필터는 훅만(정교화 후속).
- `config/EdgarProperties` — `edgar.user-agent`·`edgar.base-url`·`edgar.min-interval-ms`.

**수정**
- `DartDataSyncService`: `implements FinancialsPort` 제거(클래스 유지, P9 삭제 예정) → 포트 빈 EDGAR 단일화.
- `DataSyncScheduler`: 재무 동기화 의존 구체 DART→FinancialsPort 전환(P1 잔여 디커플 완성). **KRX/price 경로 무변경(P5)**.
- `AnnualEarningsAnalyzer`·`QuarterlyEarningsAnalyzer`: **하위호환 전환** — 연간판정 `periodType==ANNUAL || (periodType==null && fiscalQuarter==4)`, 분기는 fiscalQuarter!=null. KR(periodType null) 경로 보존 + NPE 방어.
- `FinancialStatementRepository`/`StockRepository`: 연간 null-quarter finder·ticker/cik finder 추가(additive).
- `application.yml`: edgar 설정.
