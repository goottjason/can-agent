# 장중 현재가 저장 멱등화 (duplicate-key 에러 제거 + 현재가 최신화)

- **날짜**: 2026-07-14
- **리스크**: 표준(영속화·관측성. 주문/사이징/임계값·게이트 무관)
- **발단**: 실매매 활성화 장중 관찰 중 매 5분 사이클마다 `현재가 저장 실패: <SYM> - duplicate key value violates unique constraint "ukgeg87amvaceg0ls3id20pwq0r"` 다발 발견.

## 근본원인
- `stock_prices` 테이블 `(stock_id, date)` UNIQUE (`StockPrice.java:8-9`) — 하루 종목당 1행(일별 OHLC).
- `IntradayMonitorWorker.saveCurrentPrice()`가 존재확인 없이 `new StockPrice(stock, todayEt, spot×4, 0L)` + `save()`(순수 INSERT). 당일 첫 사이클만 성공, 이후 매 사이클 유니크 위반 → catch 로그.
- 올바른 헬퍼(`StockPriceUpserter`)가 있었으나 이 경로만 미사용.
- 영향: 데이터 손상·매매영향 없음(신호는 live fetch값 사용), 그러나 대시보드 오늘 현재가가 **첫 사이클값에 고정(stale)** + ERROR 로그 노이즈.

## 변경 (선택지 A — 멱등 upsert-갱신)
| 파일 | 변경 |
|------|------|
| `domain/stock/StockPrice.java` | `applyIntradaySpot(BigDecimal price)` 추가 — close 갱신 + high=max/low=min 확장, **open·volume·changeRate 보존**, null 가드 |
| `service/StockPriceUpserter.java` | `upsertIntradaySpot(Stock, LocalDate, BigDecimal)` 추가 — 오늘 행 없으면 임시행 INSERT, 있으면 조회 엔티티에 `applyIntradaySpot` 후 명시 `save()`(REQUIRES_NEW 내, 커밋 보장) |
| `worker/IntradayMonitorWorker.java` | `saveCurrentPrice()`를 순수 INSERT → `upsertIntradaySpot` 위임으로 교체. catch·로그 유지 |

스키마 변경 없음 → 마이그레이션 불필요.
