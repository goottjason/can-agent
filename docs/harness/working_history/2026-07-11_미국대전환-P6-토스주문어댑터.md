## 무엇을 했나

### 1. BrokerPort broker-중립 재설계 (§1.1)
KIS DTO 반환 → broker-중립 값타입. 신 시그니처:
```
OrderResult placeBuy(String symbol, OrderSpec spec)
OrderResult placeSell(String symbol, OrderSpec spec)
OrderResult modify(String orderId, OrderSpec spec)
OrderResult cancel(String orderId)
BrokerBalance getBalance()
OrderStatus  getOrder(String orderId)
BigDecimal   getCurrentPrice(String symbol)   // 실패 시 0
```
신규 값타입(`com.canagent.port.dto`):
- `OrderSpec` sealed — `Notional(orderAmount)` / `Limit(qty, price)`. 팩토리 `notional()`·`limit()`.
- `OrderResult(success, orderId, message, filledQty, avgFillPrice)` — 팩토리 `accepted()`·`failure()`.
- `BrokerBalance(success, availableCash, totalEval, holdings, message)` + `Holding(symbol, name, quantity, avgBuyPrice, evalAmount)`.
- `OrderStatus(orderId, status, filledQty, avgFillPrice, commission, tax, message)` + `Status` enum(PENDING/PARTIAL_FILLED/PENDING_CANCEL/PENDING_REPLACE/CLOSED/UNKNOWN).

### 2. TossBrokerAdapter (신규)
`@Component @ConditionalOnProperty("toss.broker.enabled")` — 프로퍼티 없으면 미생성(현재 국내 운영과 무충돌). TossTokenProvider Bearer·TossProperties 재사용.
- 엔드포인트: `POST /api/v1/orders`(+`/{id}/modify`·`/{id}/cancel`·`GET /{id}`), `GET /api/v1/accounts`·`/assets`·`/exchange-rate`.
- 소수점 매수 = 금액기반 `orderAmount`(MARKET 자동라우팅), 지정가 = 정수 LIMIT.
- 모든 필드명 **명명 상수 집중**(FIELD_ORDER_ID 등). 401→토큰 invalidate·429 경고(TossCandleClient 패턴).

### 3. KIS 어댑터 마이그레이션
`KoreaInvestmentApiClient` = 신 인터페이스 구현 + `@Primary`(국내 기본 유지). KIS DTO는 내부 private 매핑용으로만 잔존. Notional 수신 시 현재가 조회로 `FLOOR(orderAmount/price)` 정수주 시장가 환산.

### 4. planPurchases notional화 (§3, 행위 변경)
정수 FLOOR·최소주문 정수주·`UNAFFORDABLE` 제거. 종목당 상한 = `예수금 × positionRate/100`(BigDecimal), 잔여현금 균등 이월. 출력 `orderAmount`. 불변식 `Σ orderAmount ≤ availableCash`. 소액계좌 분산 3버그의 정수 반올림 이슈 근본 해소.

### 5. MarketCalendarPort + TossMarketCalendarAdapter (신규 seam, 선적재)
`isTradingDay(LocalDate)`·`isMarketOpen(Instant)`. ET(America/New_York, DST 자동) 9:30~16:00 + 주말 판정. 크론 배선은 P7.

### 6. 호출부 4곳 재배선
TradingStrategyService(잔고→`availableCash()`, 매수 `placeBuy(Notional)`·매도 `placeSell(Limit)`), IntradayMonitorWorker(현재가/잔고 포트 소비 + planPurchases notional), PortfolioScheduler(`getCurrentPrice()→BigDecimal`), DashboardController(`getBalance()→BrokerBalance`). **템플릿 무영향**(모델 속성명·타입 불변 — qa 코드 확인).
