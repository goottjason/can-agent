# 2026-07-07 대시보드 UI 리팩토링 + 소개 페이지 정합화 결과서

## 배경

사용자 스크린샷 지적: 대시보드 상단 스타일 깨짐, 소개 페이지 어설픔, 종목 관리 페이지 미흡, 상단 동기화 버튼의 뜬금없는 위치·설명 부재. 순수 프론트(Thymeleaf+CSS) 리팩토링으로 처리(리스크 등급 **표준**, 매매 로직/임계값 무변경).

## 확정 원인

- **스타일 깨짐 주범**: `dashboard.html`의 `.stats` 바가 통계 5개(.stat-item) + 동기화 폼 4개(.manual-check)를 한 flex 행에 `margin-left:auto` 중복으로 담아 버튼이 통계 바 안에서 깨짐.
- 소개 페이지: 하드코딩 수치 일부 stale, CANSLIM 요소 매핑(L/I/M) 뒤섞임.
- 종목 관리: 인라인 스타일 남발, `.badge` 클래스가 리더보드용과 충돌.

## 변경 요약 (커밋 대상)

**프론트 (dashboard-builder, 백엔드 Java 무변경)**
- `dashboard.css`: `.stats`에서 폼 분리(`justify-content:space-between; flex-wrap`), 고아 `.manual-check` 제거. 공용 `.btn` 계열·`.manual-actions .action-grid`·소개용 `.doc-card`/`.tag` 승격(중복 인라인 제거). 반응형 2열 추가.
- `dashboard.html`: 동기화 폼 4개를 통계 바에서 분리 → 하단 "수동 작업(개발·운영용)" 2×2 그리드 카드로 이전. 각 버튼 `title` 툴팁(실제 @PostMapping 동작 기반). 라벨 교정 "재무제표 임포트(20종목)" → **"재무제표 파일 임포트"**(JSON 파일 기반, 20종목 무관).
- 소개 5종: 공통 style 인라인 제거→dashboard.css 참조. `system-canslim.html` 요소 매핑 교정(C·A·S·L·I·M = 분기·연간·수급·업종선도·기관·시장방향), 섹션 순서 통일, I=거래량 프록시 명시, 매수 게이트 `(canSlimBuy‖cupBuy) AND 총점≥120` 설명 추가, C=전년동기 대비 분기EPS 교정. 검증 불가 수치("2,763종목", "60분→2~3분") 일반화.
- `stock-list.html`: `.badge` 충돌 → `.status-badge`로 분리. `.btn` 공용화, 인라인 style → `.table-link`/`.inline-form` 클래스화, 액션/작업 버튼 툴팁, 검색·액션·통계 반응형 정돈.
